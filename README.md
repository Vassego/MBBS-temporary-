# MBBS-temporary-
This is a web application that is responsive and has been created for assisting students to search and apply for MBBS courses abroad. The application contains a minimalistic and aesthetically pleasing user interface that has been created with HTML, CSS (with Tailwind CSS), and JavaScript (with jQuery).
